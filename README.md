   # Roger Dodger

   A fun obstacle-dodging game where players test their reflexes and timing to avoid obstacles and survive.

   ## How the score works

   Score = time survived (in seconds) - (10 x number of obstacle hits)

   ## Controls

   Move with WASD or the arrow keys

   ## How to open the project

   1. Install Unity Hub and Unity **6000.0.41f1** (Unity 6).
   2. Download or clone this repository.
   3. In Unity Hub, click **Add > Add project from disk** and select the project folder.
   4. Open the project (the first load takes a while).
   5. Open `Assets/Scenes/SampleScene` and press **Play**.
